# Заявки Карловой: Яндекс → почта, Google Таблица, Worker → Telegram

Форма `client/tatiana-karlova` уже вызывает функцию `d4ekhh25kr82v2u5g51m`.
Обновите именно её, чтобы URL формы остался прежним. Загрузите `index.js` и
`package.json`, выберите поддерживаемый Node.js 22+ с `fetch`, точку входа
`index.handler`, таймаут **30 секунд** и публичный вызов без авторизации.
При создании новой версии сохраните все прежние переменные окружения.

## Яндекс: переменные окружения

| Канал | Переменные, необходимые для включения |
| --- | --- |
| Telegram через Worker | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `TELEGRAM_RELAY_URL`, `TELEGRAM_RELAY_SECRET` |
| Почта Resend | `RESEND_API_KEY`, `ADMIN_EMAIL`, `MAIL_FROM` |
| Google Таблица | `GOOGLE_SERVICE_ACCOUNT_KEY`, `SPREADSHEET_ID` |

`TELEGRAM_CHAT_ID` и `ADMIN_EMAIL` поддерживают несколько значений через запятую.
`SHEET_NAME` необязателен: по умолчанию `Заявки`.
`TELEGRAM_RELAY_URL`: `https://karlova-telegram-relay.oxion-ezhkov.workers.dev/telegram`.
`TELEGRAM_RELAY_SECRET` должен совпадать с одноимённым секретом Worker.
Токены, ключи и общий секрет нельзя помещать в HTML, Git или параметры URL.
Яндекс передаёт токен бота и ID получателей только в HTTPS-теле запроса к Worker.
Worker не хранит их и не пишет содержимое заявки или ответы Telegram в логи.

Если хотя бы одна обязательная переменная канала пуста, канал получает `skipped`.
Ошибка канала даёт `failed`, не мешая другим. HTTP 200 возвращается только если
есть хотя бы один `sent`. Если все каналы пропущены/упали — HTTP 502.
`sent` означает принятие API провайдера, а не прочтение письма или сообщения.

Получатель Telegram должен нажать «Старт» у выбранного бота. Перенос отправки
на Worker не устраняет неверный токен, блокировку бота или неверный chat ID.
При частичном успехе Telegram считается отправленным, если хотя бы один
получатель получил полное сообщение.

## Google Таблица

Дайте сервисному аккаунту (`client_email` из JSON-ключа) права редактора.
Колонки A–I:

Дата | Имя ученика | Фамилия ученика | Класс | Предмет | Цель и описание ситуации | Имя и отчество родителя | Телефон | Email

Значения записываются как RAW, без выполнения формул из полей посетителя.

## Worker

Отдельный Worker `karlova-telegram-relay`, исходник `relay-worker.mjs`.
Маршрут `/telegram`, метод POST, заголовок `Authorization: Bearer <общий секрет>`.
Без настроенного секрета закрыт (503), без правильного — 401.
Обновление через Cloudflare API должно сохранять существующие secret bindings;
при загрузке исходника укажите `keep_bindings: ["secret_text"]`.

Для локальной проверки без реальных отправок:

```sh
node --test tests/karlova-form.test.cjs
```
