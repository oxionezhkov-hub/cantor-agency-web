# Картинки для главной страницы

Страница: `index.html` (https://cantor.agency)

Файлы из этой папки доступны по адресу `https://cantor.agency/images/...`
(в `wrangler.jsonc` в качестве каталога ассетов указан корень репозитория).

## Что подключено в вёрстку прямо сейчас

| Файл | Где используется | Требования |
|---|---|---|
| `team/oleg.jpg` | Блок «Команда», портрет Олега | Вертикальный кадр 4:5 (например 1200×1500), нейтральный фон, не сток |

Имя файла менять не нужно — оно уже прописано в `index.html`.
Достаточно положить файл сюда и закоммитить.

Пока файла нет, на его месте аккуратный плейсхолдер с монограммой «ОЕ»
(битой картинки посетитель не увидит). Как только файл появится —
фото само займёт весь блок, плейсхолдер уйдёт под него.

Формат: `.jpg` подключён в вёрстке. Если хотите WebP/AVIF — положите файл
и поправьте `src` в `index.html` (строка с `/images/team/oleg.jpg`).

## Куда класть остальное

| Что | Папка | Примечание |
|---|---|---|
| Фото команды | `images/team/` | По одному файлу на человека |
| Скриншоты кабинетов, отчётов, объявлений | `images/proof/` | Персональные данные замазать |
| Логотип в вариантах из ТЗ | корень репозитория | Рядом с текущим `Frame 1000011449.svg` |

Блоков под скриншоты и логотип в вёрстке пока нет — их нужно добавить
отдельно, когда появятся реальные материалы.

## Чего не делаем

Сток-фото, сгенерированные «скриншоты Авито» и любые изображения,
изображающие несуществующие результаты, на страницу не ставим —
это прямо запрещено разделом «Content governance» в ТЗ.
