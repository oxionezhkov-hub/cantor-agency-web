# Скиллы платформы

Два самостоятельных канонических скилла:

- [Дизайн](../../.agents/skills/cantor-platform-design/SKILL.md): композиция, визуальный язык, клиентский текст, доступность, паттерны и визуальная проверка.
- [Принципы платформы](../../.agents/skills/cantor-platform-principles/SKILL.md): сценарии, данные, ИИ, обучение, подписка, интеграции и честные результаты.

`.claude/skills/` содержит короткие точки входа в те же файлы. Единственная редакция правил хранится в `.agents/skills/`. Для применения в другом чате попроси агента прочитать нужный файл; автоматическое обнаружение зависит от клиента.

## Промпт для дополнения другими агентами

```text
Дополни два скилла нашей платформы в репозитории cantor-agency-web:
1. .agents/skills/cantor-platform-design/SKILL.md — дизайн.
2. .agents/skills/cantor-platform-principles/SKILL.md — продуктовые и инженерные принципы.

Сначала прочитай оба скилла. Используй мои решения и правки из своего чата,
актуальные docs/service, код и проверенные пользовательские сценарии.
Внеси полезные дополнения прямо в соответствующий канонический SKILL.md.
В .claude/skills лежат только ссылки: не заводи вторую редакцию.

Отделяй прямое решение владельца от соглашения реализации и собственной идеи.
Для каждого нового правила укажи источник и область применения. Не считай
деталь текущего кода автоматически утверждённым продуктовым требованием.
Не возвращай удалённые владельцем элементы и не меняй согласованные правила
без более позднего указания. Не дублируй содержание между двумя скиллами.
Проверь найденные противоречия; если источник не позволяет решить их,
сохрани точное описание расхождения и сформулируй один конкретный вопрос.
Неподтверждённые идеи вынеси отдельно как предложения.

Задача — дополнить скиллы, не менять приложение и не публиковать сайт.
Не трогай чужие незавершённые изменения. Проверь структуру, ссылки и diff.
В результате дай список добавленных/уточнённых правил с источниками,
ссылки на изменённые файлы и оставшиеся вопросы. Не ограничивайся советами:
внеси обоснованные правки в файлы.
```
