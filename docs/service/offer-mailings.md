# Рассылки: контракт SpecialOffers

Решение владельца, чат 18.11.2026: платные предложения новым потенциальным ученикам в Авито. Поздняя правка владельца: убрать придуманные поля «Название плана» и «Предложение ученику» и строить интерфейс по документации API.

## Источник и степень подтверждения

Прочитана опубликованная копия OpenAPI SpecialOffers: https://apis.io/apis/avito/avito-specialoffers-api/ (проверка 18.11.2026). Официальный каталог https://www.avito.ru/developers/api-catalog, страницы developers.avito.ru и официальный `/web/1/openapi/list` из среды недоступны (ошибка открытия/403). Копия — вторичный источник, актуальность относительно действующего API и доступность для кабинета/категории преподавателя не подтверждены. До подключения сверить официальный контракт. Прежний экран планов основан на предположениях, признан ошибочным и удалён.

## Последовательность и поля опубликованной схемы

- `POST /special-offers/v1/available`: вход `itemIds`, ответ — доступность и причина отказа для каждого объявления.
- `POST /special-offers/v1/tariffInfo`: информация о доступных рассылках в тарифе; отсутствующий тариф не равен нулю.
- `POST /special-offers/v1/multiCreate`: вход только `itemIds`. Создаёт рассылки и фиксирует аудиторию, не является проверкой только для чтения. Ответ содержит `common.offers` и `dispatches`. У предложения есть `slug`, `type`, текст `offerText` и границы `expiresAt`. У рассылки — `id`, `status`, `availableAudienceCount`, доступные slug, цена сообщения и границы скидки. Неизвестный тип не должен становиться редактируемым шаблоном.
- `POST /special-offers/v1/multiConfirm`: `dispatches` с `dispatchId`, `recipientsCount`, `offerSlug`, условным `discountValue`; общий `expiresAt` — срок окончания предложения, не дата запуска. Подтверждение отправляет и оплачивает рассылку.
- `POST /special-offers/v1/stats`: период `dateTimeFrom`/`dateTimeTo`; ответ содержит `itemId`, `offerSlug`, `price`, `sentAt`, `expiresAt`, `count`, `accepted`, условный `discount`. Принятое предложение не равно контакту CRM, продаже или новому ученику. Полный отчёт SpecialOffers не подменять неполными наблюдениями по чатам.

Ни названия плана, ни свободного текста, ни общего бюджета, ни времени запуска в этих входных схемах нет. `offerText` возвращается Авито, а не вводится пользователем. Цена зависит от ответа Авито и числа получателей; нельзя придумать тариф или единицы денежных величин. Для расчёта оплаты дополнительно сверить денежные единицы, тарифный сценарий и фактический контракт.

## Текущее превью

Выбор опубликованных объявлений с поиском и фильтром города. Статус публикации не гарантирует доступность услуги. Кнопка проверки сообщает об отсутствии подключения и не создаёт рассылку. Варианты, аудитория, цены и диапазоны не выдумываются. До их получения форма подтверждения и оплаты не показывается. Нет планов, расписания, платных запросов, отправок или записи в кабинет Авито.

## Дальнейшее подключение

Серверная проверка владения объявлениями и доступности → явное создание рассылки → настройки только из ответа → подтверждённая пользователем сумма → единичная оплата/отправка → подтверждённый отчёт. Повтор/тайм-аут не должен повторно списывать средства; неподтверждённый исход сверяется с Авито. Расписание платформы, если его отдельно согласуют, является собственной серверной функцией, а не полем SpecialOffers.
