# Рабочий экран диалогов · решения владельца 16.11.2026

Прямые ответы владельца заменяют старые макеты. Реализовывать по задачам ниже; доступы/provisioning не являются приоритетом. Не выдавать локальный тестовый адаптер за доставку в Авито.

## Согласованное поведение

- Открытие раздела — очередь, кому нужно ответить. Новые обращения выше старых. Два основных фильтра: без ответа и напоминания. В списке последнее сообщение, постоянный отключаемый таймер ожидания, спокойный цвет и счётчик непрочитанного без жирного выделения. Закрытие/отказ останавливает таймер. Закрепления не нужны.
- Поиск по всем доступным данным/тексту. Поиск и фильтры находятся **над списком**, как в avito-ai-sales: иконка поиска слева; по нажатию фильтры заменяются расширенным поиском. Больших полей над всем рабочим пространством нет.
- Актуальный аватар Авито при наличии; буква при отсутствии. Возле имени город, без вымышленных «сын Игоря/дочь Марины». Нельзя подменять город человека географией продвижения. Этап остаётся плашкой на текущем месте.
- Никакой оранжевой полосы слева у выбранного элемента. Нативные видимые полосы прокрутки/слайдеры убрать или заменить нашими; прокрутку/доступность сохранить.
- В шапке диалога под именем — объявление и город. Строку «следующий шаг» убрать. Вкладки/вторичные действия («переписка», «диагностика», «оплаты», «история», закрытие, предложить время и т.д.) перенести в меню с тремя точками сверху.
- Режим ответа всегда понятен. Ручной по умолчанию: обычный редактор и отправка, Enter отправляет (Shift+Enter перенос, IME не ломать). Компактные кнопки вложений, отложенной отправки, голосового ввода только по подтверждённым возможностям интеграции. ИИ по согласованию — один заполненный вариант, три действия: отправить/одобрить, отклонить, редактировать. Автоматический режим с исключениями и правилом вмешательства человека остаётся по ТЗ.
- У каждого сообщения время, между днями разделители. Переход в конец при открытии. Цитирование нужно. Исходящее можно редактировать, **если** это разрешено API Авито. Нельзя выдумывать доступность редактирования.
- Вложения: поддержать все доступные через API виды; отдельно исследовать исходящие звонки API. Возможность звонить в интерфейсе Авито не доказывает API-возможность.
- Текст/оформление пузырьков сейчас подходят, исходящие тёмные. На телефоне при открытом чате общую навигацию скрыть.
- Черновики сохраняются автоматически, без сообщения «сохранено» и без отдельной кнопки. Хранение у нас плюс локальная офлайн-копия; ошибки/конфликты нельзя скрывать, реальное серверное хранение не имитировать.
- Быстрые правки «короче/мягче» не нужны. Один ответ — одно сообщение. Библиотеку готовых фраз как Telegram Business добавить в идеи, пока не реализовывать. Правки ИИ должны попадать в обратную связь, как в е-менеджере; не называть это дообучением модели без реального механизма.
- Заметка по иконке возле имени (индикатор при наличии); попап содержит заметку, объявление, город, другие доступные факты. Нет постоянного большого блока заметок.
- Добавить переключение «Диалоги / CRM»: те же обращения, все этапы/статусы/задачи. После диагностики можно сохранить итог, затем поставить задачу. Изменение представления не создаёт копии людей/встреч/платежей.

Один активный редактор: атомарный `/tmp/cantor-service-work.lock`; занятый запуск пропускается. Статус «готово» ставить с коммитом и доказательством приёмки. Полчасовые проходы до конца 16.11.2026 используют эту очередь и WORKLOG; отдельная вечерняя задача выключена, новых дублирующих автоматизаций не создаём.


## Граница текущей итерации

Экран и CRM проверяются на локальном демонстрационном состоянии, а не на рабочих переписках. Поле отправки вызывает адаптер, но по умолчанию он явно возвращает «не отправлено: Авито не подключён»; текст и цитата не теряются, фиктивного исходящего сообщения нет. Только подтверждённая квитанция адаптера добавляет исходящее/снимает ожидание; повтор не дублирует сообщение. Подтверждённый ручной ответ в автоматическом режиме переводит конкретный диалог на согласование — это покрыто тестом.

Режимы и правки/отклонения сохраняются; генерация ИИ, автоматическая отправка и обучение модели не подключены. История правок — материал для будущей обратной связи с действующим е-менеджером, не заявление о состоявшемся дообучении. Серверная синхронизация черновиков также не объявляется готовой: сейчас есть мгновенная офлайн-копия и состояние приложения в браузере.

Из `_worker.js` переиспользованы формат контакта `aisChatMeta` (профиль/аватар, отдельно география объявления), текстовая отправка существующего notifier-адаптера и обработка типов входящих сообщений. Факт существования этого кода не подтверждает разрешения клиента или поддержку новых операций. Каталоги [Messenger](https://developers.avito.ru/api-catalog/messenger/documentation), [Calltracking](https://developers.avito.ru/api-catalog/calltracking/documentation), [SBC Gateway](https://developers.avito.ru/api-catalog/sbc-gateway/documentation) были запрошены; доступ из среды дал 403/ошибку открытия. Поэтому исходящие звонки, изменение отправленных сообщений, отправка файлов/голосовых и отложенная доставка в этом проходе не активированы. Входящие изображения/файлы/голосовые/видео отображаются при получении безопасного HTTPS-адреса; звонок может показываться как событие, не как кнопка исходящего вызова.
