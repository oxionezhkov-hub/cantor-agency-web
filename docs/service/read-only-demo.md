# Подключение данных Добрыниной

Превью PR 328: https://cantor-service-preview.oxion-ezhkov.workers.dev/. Вход по паролю панели агентства. Используются исходные Shell, DashboardSection, AnalyticsSection, AdsWorkspace, LeadWorkspace/CRM, KnowledgeSection и CabinetPage. Дизайн, CSS, навигация, вкладки, таблицы и редакторы сохранены. Новых баннеров, подписей о чтении/источниках/демо и дополнительных разделов нет. Отсутствующие показатели показываются прочерком в исходных полях.

Данные загружаются перед ленивым импортом исходной оболочки через PreviewAccess/preview-data. На приёмке: 143 объявления в 38 городах, 187 диалогов / 1264 сообщения, 137 дневных записей с 30.06 по 16.11.2026. Источники — сохранённые KV, принудительная синхронизация с Авито не запускается. Основной mainweb и main не развёртываются.

## Источники и сопоставление

- Дашборд/аналитика: `dailyMetrics:elena-dobrynina:*`, с пагинацией. Сводные расходы, просмотры, контакты, диагностики и продажи используются в существующих карточках и отчётах за выбранный период. Статистика по объявлениям/городам, показы, оплаты/возвраты/LTV и расписание в источнике отсутствуют: вместо выдуманных значений стоят прочерки. Сводные показатели не распределяются по объявлениям искусственно.
- Объявления: `mbids:catalog:6c974a5d5326` — название, город, цена, статус, публичная ссылка. Текст описания по совпадающему AvitoId извлекается из `feedxml:elena-dobryinina-eba937`. Контакты и конфигурация фида не выдаются. Цены/названия/города подставляются в исходные таблицу и редактор.
- Диалоги/CRM: `aisales:index:6c974a5d5326` и сообщения всех принадлежащих ему `aisales:chat:6c974a5d5326:<id>`. Передаются только поля собеседника/объявления и сообщения, без внутренних черновиков/анализа модели. Исходная CRM и messenger получают эти записи вместо синтетических сценариев. Дата обращения берётся из первого сохранённого сообщения. Идентификаторы Авито с `~` поддерживаются в исходной навигации.
- Настройки: имя/предмет Добрыниной, блокировки объявлений из каталога; неподтверждённые баланс/тариф/расписание не заменяются примерами.
- База знаний: исходный общий курс; фиктивный прогресс Добрыниной не добавляется.

## Серверная защита

`GET /api/demo/bootstrap` и `GET /api/demo/chat?id=...` требуют `x-demo-password`, SHA-256 сверяется с encrypted secret Worker `DEMO_PASSWORD_SHA256`. Пароль не попадает в URL, bundle, localStorage, sessionStorage или git. Персональные данные не входят в публичные assets. Ответы: `Cache-Control: no-store, private`, без CORS. После перезагрузки нужен вход.

Фиксированная привязка к кабинету `6c974a5d5326` / проекту `elena-dobrynina`, ID диалога проверяется по индексу. Все изменяющие методы `/api/demo/*` возвращают 405 до чтения источников; прочие `/api/*` и `/_serverFn*` заблокированы. В Worker нет внешнего fetch, OAuth, синхронизации, отправки, ставок, публикации, ИИ или KV put/delete; ключи account/token не читаются. Изменяющие обработчики исходных CRM/объявлений для этого кабинета возвращают обычный отказ в правах, не записывают изменения и не показывают служебных предупреждений заранее.

Конфигурация отдельного Worker: `service-shell/wrangler.preview.jsonc`. Публикация выполняется отдельно от основного `wrangler.jsonc`, без migrations и pull/sync.

## Проверки

Typecheck, lint, npm test, preview build. Предметные проверки Worker проверяют авторизацию, кабинет, пагинацию, проекцию полей, отказ всех изменяющих методов и закрытие при ошибке источника. `preview-data.test.ts` проверяет замену синтетических записей, исходные сообщения/атрибуцию объявления, фактическую сводную аналитику, отсутствие фиктивных оплат и запрет изменений.

`node scripts/ops/read-only-browser-check.mjs <url> <artifact-dir>` использует DASHBOARD_PASSWORD из разрешённого окружения и проверяет исходную оболочку на 1440/390: шесть разделов, исходные CSS-контейнеры, вкладки аналитики/объявлений, редактор, поиск, CRM, переписки, переходы по Avito ID с `~`, отсутствие новых подписей/NaN/ошибок/изменяющих запросов. Для облака используется CANTOR_BROWSER_VALIDATED_TRANSPORT=1 с проверяемым TLS Node, без отключения проверки сертификатов.
