# Данные Добрыниной в превью

Превью PR 328: https://cantor-service-preview.oxion-ezhkov.workers.dev/. Сохранены исходные оболочка, дизайн, вкладки и шесть разделов. В демо загружаются данные октября–ноября 2026 года: 216 объявлений (активные и с показателями периода), 173 диалога / 1 229 сообщений, 48 дневных срезов общей аналитики, месячные показатели по объявлениям, 153 текста, 1 276 фотографий и ставки для 183 карточек.

Статистика аккаунта содержит показы, просмотры, контакты и расходы за 1 октября–17 ноября. По объявлениям доступны полные итоги октября и 1–17 ноября, а дневная статистика по объявлениям — за 1–17 ноября. Для периода вне этих границ интерфейс не подставляет вымышленные показатели. Диалоги с активностью в октябре–ноябре размечены по просмотренной переписке: новый контакт, запись, итог встречи, ученик, неявка или закрыто. Оплаты и записи не создаются без подтверждения в источнике.

## Источники

- Авито: текущие карточки, архивные объявления с показателями октября–ноября, детализация и ставки. Объявления соединяются с фидом по AvitoId и постоянному Id автозагрузки.
- Аналитика: чтение статистики Avito v2 за октябрь и ноябрь и ежедневной статистики ноября. Суммы расходов в копейках конвертируются в рубли.
- Диалоги: сообщения Avito за октябрь–ноябрь и сохранённые вручную проверенные этапы. Тишина не считается отказом.
- Автозагрузка: фактические Google Sheet, вкладка, XML-ссылка, отчёт и строка с повторяющимся Id.

## Доступ и границы

`GET /api/demo/bootstrap`, `GET /api/demo/chat?id=...` и `GET /api/demo/image?adId=...&index=...` доступны после пароля. Успешный вход выдаёт HttpOnly/Secure/SameSite cookie на 30 дней; пароль не хранится в localStorage, sessionStorage, bundle или git. Ответы с личными данными закрыты `Cache-Control: no-store, private`. Фотографии передаются через защищённый маршрут с ограниченным списком источников.

Весь набор хранится сжатым в отдельном KV превью и привязан к кабинету `6c974a5d5326`. Изменяющие методы `/api/demo/*` отвечают 405; прочие рабочие API закрыты. Обновление или публикация карточек, ставки, отправка сообщений и синхронизация с Avito не выполняются. Развёртывается только отдельный Worker превью, без миграций или развёртывания `mainweb`/основного приложения.

Конфигурация: `service-shell/wrangler.preview.jsonc`. Источник конфигурации и ограничения описаны в `service-shell/scripts/ops/preview-worker.mjs`.

## Интерактивная песочница диалогов и CRM

По прямому запросу владельца от 18.11.2026 защищённый снимок доступен для интерактивной работы с обращениями, сообщениями, задачами, заметками, оплатами и диагностикой. Все изменения и новые вложения хранятся **только в памяти открытой вкладки** и теряются при полной перезагрузке/закрытии. Они не записываются ни в источники снимка, ни в реальный кабинет Авито, ни в постоянное браузерное хранилище. Исходящие сообщения имитируются локальным адаптером и не отправляются адресатам. Изменяющие запросы `/api/demo/*` по-прежнему запрещены. При отсутствии заданных окон время диагностики можно указать вручную для проверки сценария; это не подтверждённое расписание преподавателя. Постоянные плашки о песочнице в интерфейс по решению владельца не добавляются.
