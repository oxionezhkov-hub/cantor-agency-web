# Демо Добрыниной: только чтение

Цель — показать реальные данные в PR 328 без возможности изменить кабинет Авито, отправить сообщение или записать изменения в рабочую панель. Отдельное превью: https://cantor-service-preview.oxion-ezhkov.workers.dev/. Вход по паролю панели агентства. Основной mainweb и main не развёртываются.

`service-shell/src/preview.tsx` подключает `ReadOnlyDemo`; прежняя интерактивная синтетическая оболочка остаётся в исходниках для дальнейшей разработки, но в это превью не включается.

## Источники

Worker `scripts/ops/dobrynina-source.mjs` читает строго заданные ключи и префиксы существующих KV. Аккаунт `6c974a5d5326`, проект `elena-dobrynina`; параметры клиента не могут их заменить.

- Дашборд и аналитика: `dailyMetrics:elena-dobrynina:*`, с пагинацией. Расход, просмотры, контакты, диагностики и продажи — сохранённые сводные показатели панели. Период выбирается пользователем, отсутствующие дни явно отмечены. Показы, разрез расходов по городу/объявлению и выручка не выдумываются.
- Объявления: `mbids:catalog:6c974a5d5326`, город, название, цена, статус, публичная ссылка. Только текст описания по совпадающему AvitoId извлекается из сохранённого XML `feedxml:elena-dobryinina-eba937`. Он подписан как версия автозагрузки, которая может отличаться от опубликованной. Контактные данные и конфигурация фида не выдаются.
- Диалоги: `aisales:index:6c974a5d5326`, сообщения открытого диалога — `aisales:chat:6c974a5d5326:<id>`. ID проверяется по индексу этого кабинета. Черновики, анализ модели и внутренние поля не выдаются. Чтение KV не меняет отметку прочтения в Авито.
- База знаний: существующий общий курс, без выдуманного прогресса Добрыниной. Локальные отметки обучения явно подписаны как отметки устройства.
- Настройки: подтверждённый владелец, предмет, источники, время чтения и режим доступа. Баланс, тариф, расписание, оплаты, возвраты и LTV не представлены в подключённых ключах — интерфейс сообщает об отсутствии данных. Записи и оплаты не выводятся из текста переписки.

На приёмке 17.11.2026: 143 объявления, 38 городов, 187 диалогов и 137 дней метрик. Каталог обновлён 12.11, индекс диалогов — 17.11; последняя дата метрик — 16.11. Даты обновления показаны в интерфейсе. Это чтение сохранённых источников, а не принудительная синхронизация с Авито.

## Запрет изменений и доступ

Только два маршрута данных: `GET /api/demo/bootstrap` и `GET /api/demo/chat?id=...`. Все прочие методы `/api/demo/*` возвращают 405 до чтения источников; остальные `/api/*` и `/_serverFn*` остаются заблокированными. Нет внешнего fetch, синхронизации, OAuth, отправки, изменения ставок, публикации, вызова ИИ, платежей или KV put/delete. Worker не читает ключи `account:*` и `token:*`.

Оба маршрута требуют `x-demo-password`; его SHA-256 сверяется с секретом Worker `DEMO_PASSWORD_SHA256`. Секрет содержит только digest пароля, а не пароль или учётные данные Авито. Пароль живёт только в памяти страницы; он не включён в bundle, URL, localStorage или sessionStorage. Переписки также не сохраняются в хранилище браузера. Logout очищает состояние; перезагрузка требует нового входа. Ответы данных: `Cache-Control: no-store, private`, без разрешения CORS. Публичные assets содержат только код и общие учебные материалы, без выгрузки переписок и персональных записей.

Конфигурация отдельного Worker описана в `service-shell/wrangler.preview.jsonc`. При публикации через API используются те же модули/имена bindings, assets запускаются через Worker (`run_worker_first: true`). Не выкладывать основной `wrangler.jsonc`, не запускать migrations или pull/sync. Секрет задаётся защищённым способом, никогда не попадает в git или отчёт.

## Проверки

`npm run typecheck`, `npm run lint`, `npm test`, `npm run build:preview`. Предметные проверки `scripts/ops/dobrynina-source.test.mjs` проверяют отказ без пароля, блокировку изменяющих методов, изоляцию кабинета, пагинацию, проекцию полей и закрытие при ошибке источника.

`node scripts/ops/read-only-browser-check.mjs <url> <artifact-dir>` использует `DASHBOARD_PASSWORD` из разрешённого окружения. Проверяет вход/неверный пароль, шесть разделов, реальные объявления/поиск, вкладки аналитики, загрузку сообщений, отсутствие редакторов/внешних запросов/изменяющих методов, выход и повторный вход на 1440/390. Для облака применяется существующий проверенный TLS-транспорт Node (`CANTOR_BROWSER_VALIDATED_TRANSPORT=1`), без отключения проверки сертификатов.
