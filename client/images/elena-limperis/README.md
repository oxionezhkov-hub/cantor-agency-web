# Фото для страницы Елены Лимперис

Страница: `client/elena-limperis` (https://cantor.agency/client/elena-limperis)

Загрузите сюда фотографии со следующими именами файлов — они уже подключены в вёрстку:

| Файл | Где используется | Рекомендации |
|---|---|---|
| `hero.jpg` | Главный экран (справа) | Вертикальный портрет, крупный план |
| `about.jpg` | Блок «О себе» | Портрет, вертикальный кадр (соотношение ~3:4) |
| `contact.jpg` | Блок «Контакты» | Портрет или рабочий кадр (урок, кабинет и т.п.) |
| `review-1.jpg` … `review-4.jpg` | Карусель «Что говорят ученики» | Скриншоты отзывов из Instagram/Telegram |

Можно добавить больше `review-N.jpg` — просто скопируйте карточку в HTML-файле `client/elena-limperis` (блок `#reviewsTrack`).

До загрузки реальных фото на месте изображений будет пустая рамка (плейсхолдер не создавался, чтобы не публиковать фейковые фото).
