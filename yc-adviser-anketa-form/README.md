# Анкета эдвайзеров → Google Таблица (через Yandex Cloud)

Функция принимает POST с анкеты `adviser-anketa` и дописывает строку в ту же
Google Таблицу, куда сейчас пишет Apps Script (лист **«ЭДВАЙЗЕРЫ»**). Сделано
по образцу `yc-avito-anketa-form`, с тем же сервисным аккаунтом Google.

Зачем: адрес `functions.yandexcloud.net` открывается из РФ и без VPN, и с VPN,
в том числе при ограничениях мобильного интернета («белые списки»), когда
`script.google.com` может быть недоступен. Сама запись в Google Таблицу идёт
уже с сервера Яндекса, так что доступность Google у человека не важна.

Как работает анкета:
1. Сначала отправляет ответы в эту функцию и ждёт `{"ok": true}` (до 12 секунд).
2. Если функция ответила ошибкой, не ответила или адрес ещё не подключён,
   анкета сразу сама отправляет ответы напрямую в Apps Script, как раньше.
3. Только если не прошёл и второй способ, человек видит сообщение об ошибке
   отправки со ссылкой на Telegram Олега.

## 1. Google Таблица

1. Откройте таблицу, куда сейчас падают анкеты (лист «ЭДВАЙЗЕРЫ»).
2. Проверьте, что колонки A–P в первой строке идут в таком порядке — функция
   пишет строки именно так (это тот же порядок, в котором анкета шлёт поля
   в Apps Script). Колонки с результатами — по каждому направлению из анкеты
   отдельная колонка, независимо от того, что человек отметил:

   | A | B | C | D | E | F | G | H | I | J | K | L | M | N | O | P |
   |---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
   | Дата | Имя | Telegram | Телефон | Направления | Авито | Profi.ru | Reels/Shorts | Блогеры | VK Ads | Яндекс.Директ | Telegram-канал | YouTube | SMM/Контент | Воронки | Другое |

   Если в таблице порядок другой — напишите мне, поправлю `COLUMNS` в `index.js`.
3. **Настройки доступа (Share)** → добавьте email сервисного аккаунта
   (`client_email` из JSON-ключа — тот же, что у таблиц Анны Дейнеги, Светланы
   Идрисовой и Авито) с правами **Редактор**.
4. Скопируйте **ID таблицы** — часть ссылки между `/d/` и `/edit`.

## 2. Разверните функцию в Yandex Cloud

```bash
cd yc-adviser-anketa-form
npm install --omit=dev

yc serverless function create --name=adviser-anketa-form

yc serverless function version create \
  --function-name=adviser-anketa-form \
  --runtime=nodejs18 \
  --entrypoint=index.handler \
  --memory=128m \
  --execution-timeout=10s \
  --source-path=. \
  --environment GOOGLE_SERVICE_ACCOUNT_KEY='<весь JSON-ключ сервисного аккаунта одной строкой>' \
  --environment SPREADSHEET_ID='<ID таблицы с шага 1.4>' \
  --environment SHEET_NAME='ЭДВАЙЗЕРЫ'

# Разрешить вызовы без авторизации (анкета зовёт функцию прямо из браузера):
yc serverless function allow-unauthenticated-invoke --name=adviser-anketa-form
```

То же самое можно сделать в консоли: **Cloud Functions → Создать функцию →
Node.js 18**, вставить `index.js` и `package.json`, точка входа
`index.handler`, таймаут 10 с, добавить три переменные окружения и включить
**«Публичная функция»**.

| Переменная | Что это | Откуда взять |
|---|---|---|
| `GOOGLE_SERVICE_ACCOUNT_KEY` | JSON-ключ сервисного аккаунта, **целиком, в одну строку** | Скопируйте из функции Авито / Анны Дейнеги / Светланы Идрисовой (вкладка «Переменные окружения») |
| `SPREADSHEET_ID` | ID таблицы с анкетами | Шаг 1.4 |
| `SHEET_NAME` | Название листа | `ЭДВАЙЗЕРЫ` |

Если переменные не заданы, функция отвечает ошибкой — анкета тогда
автоматически отправит ответы напрямую в Apps Script, заявка не потеряется.

## 3. Подключите адрес к сайту

HTTP-адрес функции вида `https://functions.yandexcloud.net/xxxxxxxxxxxxxxxxxxxx`
(**Cloud Functions → adviser-anketa-form → Обзор**) впишите в константу
`YC_FUNCTION_URL` в начале `<script>` в файле `adviser-anketa` (или пришлите мне).
Пока константа пустая, анкета работает как раньше — напрямую через Apps Script.

## Проверка

```bash
curl -X POST '<HTTP-адрес функции>' \
  -H 'Content-Type: application/json' \
  -d '{"fields":{"name":"Тест","telegram":"@test","channels":"Авито","result_avito":"проверка"}}'
# → {"ok":true} и новая строка в листе «ЭДВАЙЗЕРЫ»
```

## Обновление функции

После правок в `index.js` создайте новую версию той же командой из шага 2
(переменные окружения нужно указывать заново при каждой новой версии).
