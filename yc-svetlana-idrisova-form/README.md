# Заявки Светланы Идрисовой

Схема: форма → Яндекс → Google Таблица / Resend / Cloudflare Worker → Telegram.
Worker общий с Карловой, но бот, получатели, заголовок заявки и таблица задаются
функцией Светланы. Секреты в браузер не передаются.

## Обновление Яндекса

Обновите существующую функцию **d4efkkp6c9hf55k82qrf**:
загрузите `index.js` и `package.json`, используйте поддерживаемый Node.js 22+,
точку входа `index.handler`, память 256 МБ и таймаут 60 секунд.
Сохраните публичный вызов без авторизации и все переменные Светланы.
Адрес функции в `client/svetlana-idrisova` менять не требуется.

Добавьте две переменные:

- `TELEGRAM_RELAY_URL=https://karlova-relay.helpmedoctor.ru/telegram`
- `TELEGRAM_RELAY_SECRET` — тот же общий секрет, который уже установлен в Worker.

Остальные настройки — именно Светланы:

| Канал | Необходимые переменные |
| --- | --- |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, обе переменные relay выше |
| Почта | `RESEND_API_KEY`, `ADMIN_EMAIL`, `MAIL_FROM` |
| Google Таблица | `GOOGLE_SERVICE_ACCOUNT_KEY`, `SPREADSHEET_ID` |

`ADMIN_EMAIL`: получатель Светланы (`kotenok8595@mail.ru`, если он не менялся).
`TELEGRAM_CHAT_ID`: получатель Светланы (`1761494459`, если он не менялся).
Несколько почт или ID перечисляйте через запятую. Получатель должен нажать
«Старт» у выбранного бота. `MAIL_FROM` — адрес на подтверждённом домене Resend.
`SHEET_NAME` необязателен, по умолчанию `Заявки`.

Канал с незаполненной обязательной переменной пропускается (`skipped`). Ошибка
одного канала не мешает остальным. HTTP 200 означает, что хотя бы один канал
принял заявку. В `result` видны `sent`, `skipped`, `failed`; в `diagnostics` —
безопасные коды ошибок Telegram и почты без содержимого заявки и ключей.
Некорректный необязательный Email остаётся в тексте заявки, но не передаётся
в почтовый заголовок `reply_to`, чтобы не вызывать Resend 422.

## Таблица

Сервисному аккаунту (`client_email` в JSON-ключе) нужны права редактора.
Сохраняется существующий порядок колонок A–J:

Дата | Имя ученика | Фамилия ученика | Класс | Формат занятий | Цель и описание ситуации | Имя и отчество родителя | Телефон | Email | Согласие на рекламную рассылку

Данные записываются как RAW, без выполнения формул из полей анкеты.
