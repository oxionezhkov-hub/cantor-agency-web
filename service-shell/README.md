# Оболочка сервиса Cantor

Черновик кабинета репетитора. Это не страница сайта агентства и не выкладка на cantor.agency.

## Продукт и ТЗ

Полный документ владельца, разбор текущей реализации и доработанное ТЗ находятся в [docs/service](../docs/service/README.md). Начать разработку следует с границ релиза и модели данных: текущая оболочка не реализует рабочий путь от обращения до оплаты.

## Облачное превью

[Открыть текущую версию](https://cantor-service-preview.oxion-ezhkov.workers.dev). Отдельный Worker без производственных подключений; обновляется без мержа main. Сборка: `npm run build:preview`. Проверки и процесс публикации описаны в [WORKLOG](../docs/service/WORKLOG.md).

## Где смотреть

- Меню и экраны: `src/features/service/Shell.tsx`, `src/features/service/sections.ts`
- Дашборд: `src/features/service/views.tsx`, функция `DashboardSection`
- Цифры демо: `src/features/service/data.ts`
- Подписка, баланс, блокировки: `src/features/cabinet/`

Разделы меню: Дашборд, Аналитика, Мои объявления, Мои диалоги, База знаний, Настройки.

## Запуск

```bash
cd service-shell
npm install
npm run dev
```

## Что уже есть на дашборде

Текущий месяц. Шаги: показы, просмотры, контакты, диагностики, продажи. Под шагом процент конверсии и цена. Показов в исходной статистике не было: в демо у ЕГЭ 920, у ОГЭ 740.

Города не режутся по объявлениям. Подсказки: три срочные, остальные за «Ещё», ссылка ведёт в раздел.

## Куда не мержить вслепую

Деплой `main` заливает весь репозиторий на хостинг. Пока ветка не влита, на сайт это не попадает.
